# learning-codex

Bu depo, komut satırından isim alıp kullanıcıyı selamlayan basit bir Python aracını içerir.

## Kullanım

```bash
python greet.py <isim>
```

Örnek:

```bash
python greet.py Ada
```

Çıktı:

```
Hello, Ada!
```

## Testler

Projede pytest kullanılarak yazılmış otomatik testler bulunur. Testleri çalıştırmak için:

```bash
pytest
```
